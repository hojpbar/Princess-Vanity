## 📌 1. แนวคิดและกติกาของเกม (Concept & Rules)

**Princess Vanity** เป็นเกมจำลองการแต่งตัวและจัดโต๊ะเครื่องแป้งของเจ้าหญิงก่อนออกไปงานเต้นรำยามราตรี ผู้เล่นต้องใช้ความเข้าใจเกี่ยวกับ **Sorting Algorithm** ในการเรียงลิปสติกให้เป็นระเบียบจากขนาดเล็กไปใหญ่ก่อนระฆังเที่ยงคืนจะดัง!

### 🎮 รูปแบบการเล่นมี 2 ฉากหลัก:

1. **💄 ฉากที่ 1: จัดลิปสติกให้เรียง (Inversion Challenge - Manual Sort)**
   * **กติกา:** สลับลิปสติก **เฉพาะคู่ที่อยู่ติดกัน** เท่านั้น เพื่อเรียงลิปสติกจากน้อยไปมาก
   * **การคำนวณคะแนน:** เกมคำนวณจำนวนการสลับขั้นต่ำที่เป็นไปได้ด้วยค่า **Inversions** หากสลับได้จำนวนครั้งน้อยที่สุดพอดี (Optimal) จะได้คะแนนโบนัสสมบูรณ์แบบ
   * **เงื่อนไขแพ้-ชนะ:** เรียงครบภายในจำนวนครั้งที่กำหนดเพื่อผ่านด่าน / หากสลับเกินโควตา มนตร์นางฟ้าจะลดลง (พลังชีวิต -1)

2. **💃 ฉากที่ 2: เรียงให้ไวที่สุด (Algorithm Race)**
   * **กติกา:** ระบบจะสุ่ม "ลักษณะข้อมูล" ของลิปสติกมา 4 รูปแบบ (เกือบเรียงแล้ว, เรียงกลับหลัง, สลับที่กันหมด, ขนาดซ้ำกันเยอะ) ผู้เล่นต้องวิเคราะห์ลักษณะข้อมูลและเลือก **Sorting Algorithm ที่เหมาะสมที่สุด**
   * **การคำนวณคะแนน:** วัดจากจำนวนจังหวะการทำงาน (Operations / Steps) จริง หากเลือก อัลกอริทึมที่ใช้ Operations น้อยที่สุดจะได้รับคะแนนโบนัสสูงสุด

## 🧠 2. การนำ Sorting Algorithm มาใช้เป็นแกนหลักของเกม

 Sorting Algorithm คือหัวใจและ mechanics หลักของเกมนี้โดยตรง:

* **Bubble Sort (สลับคู่ติดกัน):**
  * ถูกนำมาใช้ใน **ฉากที่ 1** ผู้เล่นทำหน้าที่แทนลูปของ Bubble Sort โดยการสลับคู่ที่อยู่ติดกัน
  * ใช้ทฤษฎี **Inversion Count** เพื่อคำนวณการสลับที่น้อยที่สุดจริงทางคณิตศาสตร์
* **การเปรียบเทียบเชิงลึกในฉากที่ 2 ( Algorithm Race):**
  * เกมรันโค้ด Sorting Algorithms จริงที่ทำการ **Instrumented Step-by-Step Recording** เพื่อบันทึกจังหวะการเปรียบเทียบ (Compare) และการเขียนค่า (Swap/Write)
  * รองรับ **5 อัลกอริทึมหลัก**:
    1. **Bubble Sort:** ประสิทธิภาพสูง $O(n)$ กับข้อมูลที่ *เกือบเรียงแล้ว* (Nearly Sorted)
    2. **Selection Sort:** จำนวนการสลับน้อยที่สุด เหมาะกับกรณีการสลับมีต้นทุนสูง
    3. **Insertion Sort:** เร็วมากสำหรับข้อมูลขนาดเล็กหรือข้อมูลที่เกือบเรียงแล้ว
    4. **Quick Sort (Lomuto Partition):** ประสิทธิภาพ $O(n \log n)$ สำหรับข้อมูลสุ่มทั่วไป
    5. **Merge Sort:** ทำงานเสถียร $O(n \log n)$ เสมอในทุกรูปแบบข้อมูล

## 🛠️ 3. โครงสร้างเทคโนโลยีและการพัฒนา

* **Single-file Application:** รวมโครงสร้าง HTML, สไตล์ CSS และลอจิก JavaScript ไว้ในไฟล์ `index.html` เพียงไฟล์เดียว ง่ายต่อการนำขึ้นโฮสติ้งและโหลดประมวลผลบนเบราว์เซอร์
* **ไม่มี Dependency แหล่งภายนอก:** พัฒนาด้วย Vanilla JS และ CSS3 Pure Rendering ทำให้สามารถเปิดเล่นได้ทันทีผ่านเบราว์เซอร์ทุกชนิดโดยไม่ต้องติดตั้งโปรแกรมเพิ่มเติม

## 👨‍💻 4. ตำแหน่งโค้ดหลัก (Code Architecture Guidelines)

ภายในไฟล์ `index.html` มีการใส่คอมเมนต์อธิบายการทำงานไว้อย่างชัดเจนตามหัวข้อดังนี้:

* `SECTION 1: SORTING ALGORITHMS (instrumented versions)` - โค้ดอัลกอริทึม Bubble, Selection, Insertion, Quick, และ Merge Sort พร้อมตัวบันทึก Recorder
* `SECTION 2: ANALYSIS HELPERS` - ฟังก์ชันคำนวณ Inversions, ตรวจสอบสถานะการเรียงลำดับ และการสร้างชุดข้อมูลสุ่ม
* `SECTION 3 & 4: GAME STATE & MODE 1` - ระบบจัดการเกมฉากจัดลิปสติกแบบ Manual
* `SECTION 5: MODE 2 (RACE)` - ระบบเล่น Animation แสดงขั้นตอนการทำงานของอัลกอริทึม
